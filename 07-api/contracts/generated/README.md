# Generated OpenAPI contracts

Copied from the project repository (`docs/openapi/`), where CI regenerates them from the
code on every pull request and fails if they drift. They are the authoritative description
of identity, authorization, scheduling, attendance and biometric.

The hand-written YAML files in `../openapi/` still document the Node services (academic,
configuration, notification, quality), which have no generator yet, plus the gateway.

To refresh: copy `docs/openapi/*.json` from the project after it changes.
